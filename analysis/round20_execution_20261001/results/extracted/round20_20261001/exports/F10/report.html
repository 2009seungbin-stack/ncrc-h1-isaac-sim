리포트 보는 법

① 맨 윗줄 — 모델 정보

관절 수 (예: 12)
로봇이 움직이는 관절(다리 모터) 수. 사족(Go2)=12, 휴머노이드(H1)=19 → 로봇 종류 확인용.
iter A / 총 B (예: 6300 / 총 8000)
A = 제출용으로 선택된 best 체크포인트의 시점(보상이 가장 높았던 반복), B = 실제로 돌린 총 반복 횟수. 둘은 다릅니다 — A 가 B 보다 많이 작으면 초반에 정점을 찍고 이후 나빠졌다는 뜻(보상 설정 의심). 아주 짧게 돌리면(예: 10회) 학습이 되기 전이라 A 가 0 으로 나올 수 있어요.
params (예: 0.29M)
정책 신경망 가중치 개수 = 모델 크기. 로봇 종류 같으면 보통 비슷.
NaN 없음(제출 파일) / NaN 발견
가중치에 '깨진 값'(계산 불가)이 있나 검사. 없음 = 제출 파일이 멀쩡하다는 뜻입니다. ⚠️ 학습 도중 발산했는지는 이것으로 알 수 없습니다 — 제출은 보상이 가장 높았던 시점(발산 *이전*)을 고르므로 발산한 학습도 여기는 '없음' 으로 나옵니다. 발산 여부는 아래 '학습 결과' 카드에서 확인하세요. (NaN 없음이 '잘 걷는다'는 뜻도 아님.)
학습시작 · 종료 · 소요
학습 시작/종료 시각과 걸린 시간. 학습 종료 시 자동 기록.

※ iter 는 '반복 횟수', 소요 는 실제 걸린 '시간' — 둘은 다릅니다(같은 iter라도 GPU·설정에 따라 시간이 달라요).

② 게이지 — 안정 ↔ 공격

  • 회색 세로 눈금 = 기본값, 색 점 = 제출값.
  • 왼쪽=안정 / 오른쪽=공격 — 오른쪽일수록 빠르고 과감.
  • 주황 공격 쪽 이동 · 파랑 안정 쪽 이동 · 회색 안 바꿈.
  • 빨강 = 추천 범위 벗어남(보행 망가질 수 있어 꼭 확인). 처음 받은 값 그대로여도 빨강일 수 있어요 — 그 항목은 직접 조정해 보라는 뜻입니다.
  • (고급) = 배포 파일에서 주석 처리돼 있던 항목을 직접 적어 넣었다는 뜻. 기본값이 0(꺼짐)인 항목이면 '켬', 기본값이 있는 항목이면 그 값을 기준으로 증감을 표시합니다.

③ 학습 결과 수치 — 실패 진단

최고 보상 (iter N)
학습 중 보상이 가장 높았던 시점과 그 반복 횟수 — 이 시점 모델을 제출용으로 자동 선택해요. iter 가 너무 초반이면 초반에 정점 찍고 이후 나빠졌다는 뜻(보상 설정 의심).
지형 난이도 (terrain level)
로봇이 견딘 지형의 어려움 단계(평지에서 시작해 험지로 자동 상승). 높을수록 거친 지형까지 정복. 0 근처에 머물면 평지조차 제대로 못 걸어 난이도가 안 올라간 것(걷기 실패). (평지 전용 학습이면 표시 안 됨.)
낙상률
에피소드가 넘어져서 끝난 비율(시간이 다 차서 끝나면 '생존'). 낮을수록 안정. 높으면 불안정 → 안전 쪽 보상(낙상 벌점↑·속도↓) 검토.
탐색 std
정책이 동작을 얼마나 무작위로 시도하는지(처음 1.0 → 학습되며 보통 0.3~0.6 으로 감소). 너무 낮으면(≈0) 한 동작에 갇힘(제자리·주저앉기), 1.0 근처면 거의 학습이 안 된 것.
발산 (divergence)
학습이 스스로 무너져 계산이 깨지는 것. 강화학습은 '앞으로 받을 보상'을 예측하는 값(가치함수)을 같이 학습하는데, 그 예측 오차가 한번 커지기 시작하면 걷잡을 수 없이 불어나 결국 nan(숫자 아님)이 됩니다. 그러면 계산을 이어갈 수 없어 학습이 그 자리에서 멈춥니다 — 요청한 횟수를 다 못 채웁니다.
⚠️ 제출물은 안전합니다. 발산 이전의 가장 좋았던 시점이 자동으로 선택되므로, 그때까지 배운 것은 그대로 남습니다. 헤더의 NaN 없음(제출 파일) 은 그래서 나오는 말이고, 발산했는지는 이 카드에서만 알 수 있습니다.
왜 생기나 — 특정 값이 잘못돼서라기보다 오래 돌릴수록 확률이 올라갑니다. 보상을 극단적으로 크게/작게 두거나, 흔들림·수직 속도를 누르는 안정 쪽 보상을 많이 풀면 더 쉽게 일어납니다.
대처 — ① 나눠 돌리세요. 8000회를 한 번에 걸면 4000회에서 멈췄을 때 그 뒤가 통째로 날아가지만, 3000회씩 이어서 돌리면 중간 결과가 남습니다. ② 값을 한 번에 크게 바꾸기보다 조금씩 옮기며 확인하세요.
