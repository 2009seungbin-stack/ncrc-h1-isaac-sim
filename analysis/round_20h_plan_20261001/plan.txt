이번 라운드 합산 점수·시간 효율 계획 — 최대20시간
2026-10-01 / 계획만 작성. 서버 시작·학습·제출 없음.

목표
마지막 확인 Go2 88.14 + H1 88.00 = 합산176.14.
이번 라운드는 두 로봇의 검증된 합산 상승을 사용시간으로 나눈 값을 우선한다.
Go2 90점은 계속 목표로 두되, 합산 상승을 위해 H1의 저비용 실험도 한 쌍만 한다.
공식 점수 기대 상승 확률을 추정할 자료가 없어 수학적으로 최적이거나 몇 점 오른다고 보장하지 않는다.
시뮬레이션 성능·생존·제출 문서의 실제 개선으로 판단한다.

총 예산:20시간 = 공통진단0.75 + H1탐색2.25 + Go2탐색4.75 + 승자확인8 + 최종검증2 + 복구/변동/종료여유2.25.
건강한 일반 경로는 최대17.75시간. 20시간을 채우는 것이 목적이 아니다.
이미 이번 라운드에서 사용한 시간이 있으면20에서 먼저 빼고 후보 수/학습량을 줄인다.
서버 켜짐부터 꺼짐까지의 실제 누적시간으로 계산한다. 시작/학습/평가/영상/export/백업/download/대기를 모두 포함한다.
최종 검증2시간과 서버 종료 여유0.5시간을 보호한다. 누적17.5시간 이후 새 학습을 시작하지 않는다.
다음 작업 예상비용+검증2시간+종료0.5시간이 남은 예산을 넘으면 그 작업을 시작하지 않는다.
이미 시작한 작업도 학습 iteration보다 실제시간 상한을 먼저 적용한다. 자동으로 예산을 연장하지 않는다.

경제성을 위한 변경
네 Go2 factorial cell 전부를 항상 돌리지 않고, 대조/회전/급변벌점 세 cell만 우선한다.
F11 조합은 두 단일 변경이 모두 유망할 때만 예산 내에서 비교한다. 상호작용을 미리 확인했다고 주장하지 않는다.
승자와 대조군을 처음부터 각각 긴 scratch 학습하는 기존 계획을 축소한다.
Go2 최종 독립 scratch 후보 하나를 기존 제출 정책과 비교한다. 별도 scratch 대조가 없으므로 보상만의 인과 효과라고 주장하지 않는다.
기존 H1 설정의 단순 장기 연장, Go2 D1의 실패한 흔들림 벌점 강화, 거대한 보상 조합 탐색은 제외한다.
중간 평가는 기존 evaluator의 --checkpoint로 actor를 직접 읽어, 매번 play/export/영상 생성을 반복하지 않는다.
H1의9000→10000은 근사+0.00385, 강한 밀침 생존-0.0293이었다. Go2의4000→5500은 근사+0.39955였지만5528회에 중단됐다.
이 둘은 과거 단일 run이며 미래 수익률로 외삽하지 않는다.

0. 서버 OFF 사전 준비
기존 후보 파일·checkpoint·평가 JSON·원본 제출 묶음을 사용한다. 보상 수정은 제공 REWARD_WEIGHTS의 값만.
환경/알고리즘/LR/entropy/관측노이즈/물리/제출 정책 필터를 변경하지 않는다.
상위 CLI에는resume/load_run/checkpoint/seed가 있으나 대회 wrapper의 허용/동작은 별도 확인한다.
명령·경로·비교표·보고서 초안은 로컬에서 준비한다. 실행 승인 질문을 위해 서버를 켜두지 않는다.
계획 요청은 학습·제출 실행 요청으로 간주하지 않으므로 이 문서 작성에서는 서버를 켜지 않았다.

1. 공통 진단:최대45분
사이트의 실제 잔여시간/마감/이번 라운드 사용시간을 재확인하고 원본 정책을 보존한다.
제공wrapper/import/README를 읽어 지원 인자를 확인한다. train.py --help는 cleanup hook 사고 때문에 사용하지 않는다.
기준 정책 성능과 재개 후50~100회의 건강을 확인한다. 가능한 경우 건강 시험은 대조군의 연속1000회 학습 초반으로 포함해 별도 재개를 줄인다.
actor/critic/optimizer finite, std 유효성, critic loss 급증, reward 이상치, contact-buffer overflow를 확인한다.
C0가5528회에 중단된 기록을 고려한다. 시험 성공이 이후1000회 안전성을 증명하지 않는다.
후보들이 같은 부모·환경 수·학습량·커리큘럼 초기화를 겪도록 맞춘다. 체크포인트는 정리 대상 밖에 보존한다.
resume 불가/불안정이면 아래 실패 경로로 바꾸고 일반 경로와 예산을 중복 사용하지 않는다.

2. H1 저비용 단일 변경:최대2시간15분
현재 R3A9000 full checkpoint에서 대조군과HY30을 각각 추가1000회.
대조:track_ang_vel_z_exp2.0. 후보:3.0. 나머지는 모두 동일.
과거8192env 로그의 collection+learning 중앙값은 약2.06초/회. 계획상2.5초/회를 가정하여 두 run 학습만 약1.39시간.
나머지약0.86시간에 시작·평가·백업을 넣는다. 실제 속도와 허용 환경 수가 다르면 반복 수를 줄인다.
world-z 회전 보상과 body-z 자체 평가의 좌표계 차이를 고려한다. 한 축의 body RMSE만 좋아졌다고 승격하지 않는다.
7개 시나리오와 강한 밀침을 같은 조건에서 비교한다. 지형 커리큘럼 회복이 부족하면 부정 결과를 확정하지 않는다.
HY30이 실패하면 두 번째 H1 보상 탐색을 자동으로 시작하지 않는다. 기존88점 정책 유지.
저비용 H1 실험은 효과 가능성이 확인되지 않은 탐색이다. 빠르게 학습된다는 사실을 높은 공식 점수 수익으로 해석하지 않는다.

3. Go2 세 후보:최대4시간45분
동일한 C0 부모에서 각각 추가1000회, 기본6144env 순차 실행.
F00:회전0.75 / action_rate_l2-0.010
F10:회전1.50 / action_rate_l2-0.010
F01:회전0.75 / action_rate_l2-0.015
선속도2.0과 나머지는 고정. 학습만 약4시간, 나머지45분은 시작·같은 조건의 평가·백업.
8192/12288env는 과거contact patch overflow 기록이 있으므로 제외한다. 동시 두 학습도 과거 총 처리량이 떨어져 제외한다.
직진 중 회전 변동, 측방 표류, 전방향 추종, 계단/요철, 밀침 회복을 본다.
재개 후1000회는 선별용이다. 아직 지형 적응이 안 됐다면 계단의 낮은 점수를 최종 능력으로 단정하지 않는다.
동작 급변 벌점을 키웠을 때 std 변화·회복 지연·추종 저하가 생기면 reward 합이 높아도 통과시키지 않는다.
짧은 후보 평가를 위해 모든 후보에서 영상/경계지형 전체를 반복하지 않는다. 최종 승자만 확대한다.

4. 결과별 추가 배분:최대8시간, 필수 소비 아님
판단 전에 검증/종료 시간을 떼고, 실제 초/iteration과 시작 시간을 다시 측정한다.
선별 게이트의 예:
  두 근사식의 대조군 대비 상승이 모두 양수, 작은 쪽+0.15점 이상, 반복 평가/시나리오에서 일관성, 설명 없는 낙상 증가 없음.
  +0.15는 작은 한 번의 승리를 경계하기 위한 운영 기준이며 통계적 유의성이나 공식 상승 보장이 아니다.
  근소한 후보는 불확실로 표시한다. 재평가/짧은 반복의 비용 대비 가치가 있으면8시간 배분에서 확인한다.
  짧은 학습의 커리큘럼 미회복은 보상 실패와 구별한다. 근거가 없으면 최종 교체를 하지 않는다.
유망 후보끼리는 min(근사식A상승,근사식B상승)/실험 전체 서버시간을 참고해 순서를 정한다.
이 비율은 잡음이 있는 휴리스틱이며 공식 기대 수익률·신뢰하한·추가학습 한계수익률이 아니다.

분기 A — 두 로봇 모두 유망
Go2 승자 하나를 새 학습 seed의scratch로최대4500회(학습약6시간).
H1은 원래9000부모에서 대조/승자를 다른 학습 seed로각1000회 반복(학습약1.39시간).
두 작업의 순수학습약7.39시간이므로 나머지0.61시간의 시작/백업 비용까지8시간 안에 맞을 때만 둘 다 한다.
시간이 넘으면 우선순위가 낮은 반복을 줄이거나 취소한다. H1은 같은 부모 재개 반복이라 독립 초기화 검증보다 약하다.

분기 B — Go2만 유망
Go2 승자 하나를scratch최대4500회. 새scratch 대조군은 이번에 만들지 않고 현재 실제 제출 정책과 비교한다.
F10과F01가 각각 모두 좋아졌다면F11을추가1000회 비교할 수 있다(학습약1.33시간).
이 조합 시험을 먼저 하고, 최종scratch 보상 파일은 그 결과로 확정한다. 조합/학습/시작의 합이8시간을 넘으면 조합은 생략한다.
4500회가 현재5500보다 반드시 낫다는 가정은 없다. 현재 제출 기준을 이기지 못하면 교체하지 않는다.

분기 C — H1만 유망
H1 승자 하나를새scratch로최대9000회(학습약6.25시간). 실제 곡선을 보고 더 일찍 멈출 수 있다.
기존R3A9000과 비교하되 서로 다른 학습 seed의 차이가 있으므로 보상 단독 효과를 단정하지 않는다.
Go2는 현재 정책을 유지하고 남은 시간을 억지로 소비하지 않는다.

분기 D — 둘 다 뚜렷한 개선 없음
추가8시간 학습을 시작하지 않는다. 필요한최종 확인만 하고 통상누적8~10시간 안에 종료한다.
이 결론은 이번에 확인한 개선이 없다는 뜻이다. 짧은 탐색에서 모든 개선 가능성이 소진됐다는 뜻은 아니다.

실패 경로 — Go2 재개 불가/반복 발산
기본Go2탐색4.75+추가배분8을대체하여 대조/단일변경 한 후보를scratch각최대4000회로 비교할 수 있다.

H1에 유망한 실측 결과가 있다면 이 비싼 대체보다 H1 독립 확인을 먼저 고려한다.

5. 최종 검증·묶음 확인:최대2시간 보호

한시드최고값·reward합·noise OFF점수로교체하지 않는다. 공식 생존은 자체무낙상으로증명되지 않는다.

90점 인증은 공식Go2시뮬60+설계/보고서30일때만 한다. 합산상승 역시 공식채점으로 최종 확인한다.

기록과 보존
원래30시간Go2계획은보존하고 이20시간계획을이번라운드의우선계획으로사용한다.

기존정책/보상/평가와미학습후보는수정하지 않았다. 새결과나공식상승은아직없다.
서버현재상태/시간은이번오프라인계획에서새로조회하지않았으며실행전재확인한다.
