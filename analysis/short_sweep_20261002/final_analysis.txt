결론
현재 우선 후보는 기존 저장 모델 F10_3000이다. 새로 800회 학습한 action/acc/linear는 control 대비 명확한 개선을 보이지 않았다.
C0와 F10_3000을 별도 조건의 7개 시나리오로 검증했으며 F10_3000이 내부 품질에서 소폭 우세했다.

4. C0_5500 및 F10_3000 별도 검증: 128환경, reset seeds 809/1201, startup seed303, terrain seed9049, G1~G7.
모델당 7 x 128 x 2 = 1792 episodes, 각 20초. 제공 학습 소스/PPO는 변경하지 않았다.

짧은 학습의 판단
모델당 256 episodes 낙상: control 2, action 1, acc 19, linear 17.

Acc/linear는 밀침 안정성이 떨어졌다. Linear의 계단 전진 추종 개선은 yaw/밀침 악화와 상충했다.
총 보상은 가중치가 달라 모델 순위에 사용하지 않았다.
