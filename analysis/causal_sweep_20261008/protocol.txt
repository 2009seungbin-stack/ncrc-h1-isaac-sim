Go2 원인 분리 비교 — 2026-10-08

승인 범위
control / torque / posture 3개를 scratch, seed42, 6144 environments, 각 2000 iterations로 순차 학습한다.
현재 서버는 시작하지 않았다. 실제 할당 시작 시각을 확인하기 전에는 실행 deadline을 만들거나 runner를 실행하지 않는다.
서버 사용 한도는 준비·학습·평가·회수·종료를 합쳐 10시간이다.
계산 deadline은 실제 서버 시작 +9시간15분 이하이며, 회수·종료에 최소45분을 남긴다.
과거 800회 실험의 측정속도로 학습만 약8.03시간이며 새로운 서버의 성능을 보장하지 않는다.
이번 범위에는 추가 후보, 추가 training seed, 공식 제출, 로컬 PC 종료가 없다.

lin_vel_z_l2=-3, ang_vel_xy_l2=-0.08, action_rate_l2=-0.01,

원본 보존
제공된 train.py/play.py/go2_task/agent_cfg.py/go2_task/env_cfg.py와 PPO 코드는 수정하지 않는다.
새 서버에서 현재 파일의 해시를 취득하고 과거 참고 해시와 비교한다. 차이가 있으면 원인을 확인한다.
보상 파일은 새 서버의 현재 원본을 보존하고, 단계 종료 및 오류 시 복구/해시를 검증한다.
정식 checkpoint model_1999.pt와 가능한 중간 모델, params, event, 학습 로그를 wrapper 정리 범위 밖에 보존한다.
남은 시간 부족이나 실패 시 다음 작업을 추가하지 않고 보존·복구·회수를 우선한다.

생존율, vx/vy/yaw RMSE 및 MAE, transient와 steady 구간, G6 충격 직후 회복, 학습 곡선을 함께 비교한다.

훈련 seed 반복이 없으므로 seed42 조건의 원인 분리 비교이며 보편적인 개선을 확정하지 않는다.

완료 조건
모든 계산 완료만으로 완료 표시하지 않는다.
원격 archive 크기/SHA256 취득 → 로컬 회수 → 동일 크기/SHA256 검증 → 안전한 하위폴더에 압축 해제 → 3개 최종모델/로그/평가결과 확인 → 분석 저장 → 할당서버 종료 확인.
