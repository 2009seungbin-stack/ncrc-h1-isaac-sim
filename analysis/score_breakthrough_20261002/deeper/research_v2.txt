점수 돌파 추가 연구 — 2026-10-02

결론

앞선 '선속도 보상 3.0을 먼저 학습한다'는 우선순위는 보류한다. 평균 전진속도 부족만으로 설명되지 않는 오차와 자체 평가의 시점 문제가 확인됐다. 새 학습 전에 평가 계약을 바로잡고, 밀침·전환 직후의 실제 궤적을 확인해야 한다. 큰 폭의 공식 점수 상승을 입증한 상태는 아니다.

이번에 완료한 연구
- F00/F10 전체 학습 로그 8,000 iteration 분석.
- 저장 체크포인트 82개 CPU 로드, actor/critic 유한성·탐색 std·저장 optimizer LR 확인.
- 실제 보존된 평가 함수로 모의환경 재현 4건, 수정된 관측/종료 계약 모의 검사 2건.
- 강한 밀침·급전환·15cm 계단 원본 JSON의 축별 오차와 구간 평균 재분석.
- 이상적인 직선 경로 32,000개의 지형 영역 노출 계산. 로봇 시뮬레이션과는 구분.
- IsaacLab/RSL-RL 원본 코드와 보상 최적화·RL 평가 연구 검토.

서버 가동, 새 학습, 공식 제출은 하지 않았다. 기존 평가기·정책·학습 설정은 수정하지 않았다. 수정 계약은 모의환경에서만 검증했으며 서버용 새 평가기를 구현·검증했다고 주장하지 않는다.

1. 선속도 보상 증가를 최우선으로 둔 근거가 충분하지 않았다

강한 밀침 GX1, 전진 명령 0.5m/s:
                         기존 C0          F10 3000
4개 구간 평균속도의 평균     0.4293           0.4720
전진속도 RMSE               0.3850           0.4013
좌우속도 RMSE               0.4537           0.4855
회전 RMSE                   0.2814           0.2279

F10은 평균적으로 명령에 더 가까이 전진하면서도 전진 RMSE는 나빠졌다. '소극적으로 걸어서 느리다'만으로 설명할 수 없다.

균등 구간 분해에서 F10 GX1 전진 MSE 중 평균 편향 제곱의 비중은 약0.51%이고 나머지는 구간 내 시간·환경별 차이다. 환경별 고정 편향도 이 나머지에 포함되므로 이를 전부 진동 또는 회복 지연으로 단정하지 않는다. 낙상 후 유효 표본 수가 달라져 균등 구간 분해와 전체 시간 가중 MSE는 정확히 같지 않다.

15cm 계단에서는 F10 전진 RMSE 0.1098 중 구간 평균 편향의 MSE 비중이 약15.6%였다. 실제 평균 부족도 있으나 대부분은 평균 편향만으로 설명되지 않는다.

따라서 다음에는 동일한 외란 이후의 0~0.2초, 0.2~0.5초, 0.5~1.0초, 1.0초 이후 오차를 나누고, 회복 시간·최대 이탈·오버슈트·정상상태 변동·환경 간 차이를 측정해야 한다. 시간별 원자료가 없어 이 분해는 아직 수행할 수 없다.

2. 자체 평가 함수의 두 문제가 모의환경에서 재현됐다

대상은 과거 결과에 사용된 보존본 t_eval.py의 run_scenario 함수다. 코드 일부를 흉내 낸 채점기가 아니라 해당 함수를 직접 불러 실행했다.

문제 A — 명령 전환 직후의 관측 지연
각 구간 시작에서 명령 텐서는 바뀌지만 정책에 주는 obs는 이전 env.step이 반환한 스냅샷이다. 따라서 첫 action은 이전 명령을 보고 나온다. 제어 주기0.02초에서 전환마다20ms의 지연이 평가 코드 때문에 추가된다.

즉시 명령을 그대로 속도로 구현하는 가상 정책을 GX5와 같은10구간 명령에 넣으면:
- 물리 오차가 없는 모의환경인데 추종점수0.9188.
- vx/vy/yaw RMSE=0.0894/0.0387/0.1095.
- 9개 전환 스텝 모두 정책 입력과 현재 명령 불일치.
- 전환 전에 모의 관측의 명령 항만 갱신하면 추종점수1.0, 세 축 RMSE0.

실제 로봇은 즉시 속도를 바꾸지 못한다. 이 수치는 실제 모델의 손실량이나 회복 가능한 공식 점수가 아니다. 실제 235차원/256차원 관측에서 명령 항 위치·스케일·정규화를 확인한 뒤 수정해야 한다. 모든 관측을 다시 계산해 노이즈까지 새로 뽑으면 비교의 난수 조건도 달라질 수 있다.

문제 B — 마지막 제한시간 리셋 상태가 채점될 수 있음
평가기의 환경 제한시간과 측정 길이가 같다. IsaacLab step은 제한시간 종료도 리셋한 다음 관측을 반환한다. 현재 평가는 terminated만 생존 마스크에 반영하고 truncated를 확인하지 않은 채 반환 후의 root velocity를 읽는다.

20초 동안0.4m/s를 완벽히 유지하는 가상 정책에서 마지막 스텝 자동 리셋을 넣으면 vx RMSE0.0133이 생긴다. 리셋을 측정 구간 밖으로 넘기면0이다.

수정 계약:
- 측정 구간은 그대로 두고 환경의 제한시간을2제어스텝 이상 뒤로 둔다.
- 측정 구간 안에서 예상하지 못한 truncated가 발생하면 평가를 정상 완료로 취급하지 않는다.
- 구간 전환 전에 정책 관측의 명령 항을 동기화한다.
- 적용된 명령·관측 명령·action 시점을 기록해20ms 단위로 검증한다.
- 원래 결과와 수정 결과를 다른 버전으로 보존한다. 과거 점수를 조용히 덮어쓰지 않는다.

두 수정 계약의 모의 검사에서는 정상 추종점수1.0을 확인했다. 실제 Isaac Sim 영향과 모델 순위 변화는 미검증이다. 평가 숫자를 바로잡는 일 자체는 로봇 성능 향상이 아니다.

3. 계단·경사를 충분히 시험했는지 아직 확인되지 않았다

현재 자체 지형은8m×8m 타일의4×4 배열이다. G5는0.4m/s로20초, G4는0.5m/s로20초를 명령한다. 잘 추종하면 각각8m/10m를 움직여 출발 타일을 벗어난다.

실제 설정의 초기 위치±0.5m, 무작위 yaw, 균등 타일 배치와 완벽한 직선 추종을 가정한32,000개 경로 계산:
- G5는 채점 시간의12.42%가4×4 타일 배열 밖에 위치.
- G4는16.49%가 배열 밖에 위치.
- G5에서 계단 고리의 평면 영역에 놓이는 시간은39.24%.

이는 이상적인 점 경로의 기하 계산이다. 실제 발 접촉·로봇 위치·물리·넘어짐을 측정한 결과가 아니며, '실제 평가의60.76%가 평지였다'고 주장할 수 없다. 계단에는 중앙 평탄부와 타일 경계가 있으므로 실제 접촉 노출을 기록해야 한다는 근거다.

새 진단에서는 위치, 타일 ID, 범위 이탈, 실제 지면 경사, 계단 통과 단수·거리·접촉 위치를 남긴다. 총 생존 시간과 실제 장애물 통과 성능을 함께 보고한다. 격리 시나리오를 더 넓은 지형으로 만들거나 통과 경로를 고정하는 변경은 별도 평가 버전에서 비교한다.

4. 후반 학습의 악화 신호를 전체 기록에서 확인했다

F10 학습 로그 중앙값:
                             2000~2799       3000~3999
평균 지형 단계                 5.9735           5.9882
탐색 std                       0.8000           0.9300
몸통 접촉 종료 비율             0.0562           0.0708
가치함수 loss                  0.2424           0.8903
action_rate 보상               -0.2202          -0.2824
선속도 추종 보상                1.5222           1.4934
회전 추종 보상                  1.1481           1.1065

지형 단계가 거의 같은데 학습 중 여러 지표가 후퇴한다. 단순한 '아직 어려운 지형을 배우는 중'만으로 설명하기 어렵다. 그러나 이 로그는 탐색 행동을 포함한 훈련 분포이고, 결정론적 제출 정책의 점수와는 다르다. 원인이나 최적 iteration이 확정된 것은 아니다.

F10의1000회 이후 value loss>10인193회 중87회(45.1%)가 수직속도 보상<-1인 이벤트의±3회 안에 있다. 그러한 인접 구간은 전체의8.77%다. 수직 보상 극단값은−10.8239이며 평상시 중앙값 약−0.08과 큰 차이가 있다. action_rate 항에는 비슷한 크기의 폭발이 관측되지 않았다.

집계 지연·공통 원인·사후 임계값 선택이 있어 인과 증거는 아니다. 나머지55%의 큰 value loss도 이 기준으로 설명되지 않는다. 이를 근거로 물리 엔진 결함이나 특정 보상 하나를 원인으로 확정하지 않는다.

82개 저장본의 actor/critic 텐서는 모두 유한하고 std는 양수였다. 따라서 후반 성능 저하를 저장 모델의NaN 때문이라고 할 근거는 없다. 이것이 optimizer 전체의 정상성이나 미래 학습 안정성을 보장하지는 않는다.

중간 모델 선별은2000/2200/2400/2600/2800을 중심으로3000과 비교한다.1200은 초기 자동 best 기준점이다. 이 범위 선정은 탐색적이며 실제 평가 우승을 미리 주장하지 않는다.

5. 보상으로 직접 고칠 수 없는 학습 분포 차이도 있다

F10의 실제 env.yaml:
- push_robot=null. 주기적 밀침은 꺼져 있다.
- 정적 마찰0.8, 동적 마찰0.6으로 범위가 고정돼 있다.
- 질량은startup에서−1~+3kg 가산 랜덤화가 있다. 도메인 랜덤화 전체가 없다는 뜻은 아니다.
- 초기 속도와 외력은0이며 명령은10초마다 재표본한다.
- 선속도 명령 범위는vx−1~2m/s, vy±0.6m/s, 회전은heading 제어 기반이다.

자체 본 평가의 명령은 대부분0.4~1m/s이고 강한 밀침·2초 급전환은 추가 시험이다. 마찰 변화와 밀침에 대한 일반화는 직접 훈련된 조건을 넘어선다. 보상만 바꿔 이를 얼마나 해결할 수 있는지는 미확인이다.

예선 규정의 값 수정 범위에서 학습 지형·밀침·마찰·관측·PPO를 바꾸는 해법은 실행안이 될 수 없다. 평가에서 분포 밖 조건을 측정하는 것과 학습 환경을 바꾸는 것은 구분한다.

6. 새 보상 실험은 진단 결과로 분기한다

아래 값은 검증되지 않은 실험 후보이며, 동시에 전부 적용하거나 모두 학습하자는 뜻이 아니다. 기준은F10이다.

관측: 충분히 안정된 이후에도 평균 선속도 편향이 주된 손실.
후보: track_lin_vel_xy_exp2.0→3.0. 다른 항 고정.
기각: 회전·생존·밀침 복구 악화를 감수한 단순 평균속도 개선만 있는 경우.

관측: 안정상태에서 반복되는 동작 급변과 속도 변동이 주된 손실.
후보: action_rate_l2−0.01→−0.015.
기각: 밀침·명령 전환의 회복 시간이 늘어 전체 오차가 나빠지는 경우.
주의: 이 항은 학습 탐색 행동도 벌하므로 결정론적 정책의 매끄러움과 같지 않다.

관측: 동작은 안정적이나 밀침·전환에 대한 응답 지연이 주된 손실.
후보: action_rate_l2−0.01→−0.0075.
기각: 정상상태 변동·관절 급변·낙상이 증가해 이득이 사라지는 경우.

관측: 원시 수직속도·종료 유형과 value loss의 큰 이상치가 반복적으로 연결됨.
후보: lin_vel_z_l2−3.0→−1.5를 별도 비교.
기각: 손실 숫자만 작아지고 실제 보행·등반·생존이 나빠지는 경우.
주의: 보상을 줄여 숫자가 작아진 것은 학습 안정성이나 성능 개선의 증거가 아니다.

발 들기 항도 단순하지 않다. feet_air_time은 발 높이가 아니라 착지 때의 공중 시간과0.5초 기준의 차이를 합산한다.0.01→0.05가 계단 높이를 직접 해결한다는 주장은 철회한다. 발 접촉·체공·발끝 간격 진단 없이 우선하지 않는다.

시간이 제한되면 위 원인 중 자료가 가장 뚜렷한 하나만 선택한다. 상충하는 후보를 합치는 것은 각각의 개선이 확인된 다음에 검토한다.

7. 연구 논문에서 가져올 것과 가져올 수 없는 것

MORSE는 실제 과제 성능을 기준으로 바깥 최적화가 보상을 조정하고, 안쪽 최적화가 정책을 훈련하는 접근이다. 현재 대회에서 그 보상 함수 생성·학습 알고리즘을 그대로 도입할 수는 없다. 가져올 수 있는 원칙은 '학습 보상 합이 아니라 별도 검증 성능으로 보상 값을 선택한다'는 것이다.

적응형 에너지 보상 연구는 속도에 따라 에너지 보상 가중치를 바꿔 보행 형태를 조정한다. 현재는 고정 값 변경만 허용되므로 논문 성능을 그대로 재현하거나 동적 가중치를 몰래 넣는 방향은 제외한다.

RL 평가 연구는 소수 학습 반복의 평균값만으로 우열을 단정하는 문제를 지적한다. A/B reset seed는 독립 학습 seed가 아니다. 기존 B를 이미 보고 후보를 설계했다면 다음 최종 검증에는 새 조건이 필요하다.

8. 공식 점수 격차를 설명하는 가설도 좁혔다

초기0.5초를 제외한 것이 자체·공식 점수 차이의 전부라는 가설을 조건부 계산했다. 공식 생존율1, 공식 추종함수exp(−3축RMSE), 명령 변경 후 단조 응답·오버슈트 없음이라는 가정이다. 모두 확인된 공식 구현은 아니다.

이 조건에서 G4 명령 전환 제외로 생길 수 있는 추가 MSE는 최대0.00208인데 격차를 설명하려면0.02482가 필요하다. G5는0.00133 대0.03273이다. 명령이 바뀌지 않는 계단·경사 시나리오의 차이는 이 단순 초기구간 가설만으로 설명되지 않는다.

이 결과는 공식 채점식을 증명하거나 일반적인 실제 로봇 오차의 상한을 제시한 것이 아니다. 공식 축·집계·생존·평가 범위의 차이를 계속 열어둬야 한다. 평가기의 두 시점 오류도 자체 점수가 공식보다 높은 이유를 자동으로 설명하지 않는다.

9. 다음 작업의 우선순위와 충분성 기준

1) 진단용 평가기의 관측 동기화·종료시간·시간별 기록을 구현하고 서버에서 검증한다. 기존 버전과 결과는 보존한다.
2) C0와F10 3000을 새 진단으로 비교해 평균 편향, 환경별 편향, 시간 변동, 회복 지연, 실제 지형 통과를 분리한다.
3) F10 중간 저장본을 같은 진단으로 선별한다. 새 terrain/startup/reset 조건에 최종 후보를 확인한다.
4) 확인된 실패 원인에 맞는 보상 후보 하나를 scratch 학습한다. 보상 합이 아닌 검증 성능으로 체크포인트를 고른다.
5) 보상 변경의 일반적 효과를 주장하려면 독립 학습 반복을 확보한다. 시간상 한 번만 돌렸으면 단일 run 결과라고 명시한다.
6) 시나리오별 예측을 동결하고 공식 제출 결과로 실제 상승을 확인한다. 제출은 이번 연구에서 실행하지 않았다.

기존7시간18분 미사용 기록을 현재 예산으로 자동 승인받은 것으로 취급하지 않는다. 그 규모로 다시 수행한다면 진단과 중간 모델 선별을 먼저 보호하고, 별도 학습·독립 반복을 모두 넣었다고 계획하지 않는다. 앞선7시간15분 계획은 이번 추가 진단과 반복까지 포함하지 않았으므로 그대로 '충분한 계획'이라 할 수 없다.

현재 충분히 확인된 것은 기존 제안의 약점과 다음 측정의 우선순위다. 새 정책의 큰 공식 점수 상승을 보장할 근거는 아직 없다. 이 연구로 점수가 올랐다고 보고하지 않는다.
